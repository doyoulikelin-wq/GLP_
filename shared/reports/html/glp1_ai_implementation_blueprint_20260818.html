02 / TARGET

AI 首先要看懂两个型态差在哪里

HAEGT… 是氨基酸单字母代码。模型看到序列，项目还必须补充末端化学和编号语义。

GLP‑1(7–36)NH₂30 个残基；自由 His⁷ N 端
GLP‑1(9–36)NH₂28 个残基；自由 Glu⁹ N 端
GLP‑1(7–36)NH₂ + H₂O ────▶ GLP‑1(9–36)NH₂ + His–Ala

为何只少两个残基却很难？

两条肽有 28 个残基相同。若捕获蛋白主要抓中部或 C 端，它可能同时抓住两者。选择性必须让界面依赖正靶的自由 His⁷、Ala⁸及邻近骨架，并让 9–36 的新自由 Glu⁹ N 端不适配。

为什么不能只放一个结构？

GLP‑1 是柔性肽。候选若只适配一个漂亮姿势，可能在溶液中失效。正靶和每个负靶都要建立，评价可结合状态、最坏型态与模型分歧。

产品范围先锁定：本页面按“GLP‑1(7–36)NH₂这一肽型态专一捕获”实施。GLP‑1(7–37)本身是天然完整活性型，不是失活负靶；如果产品声称捕获“完整/活性GLP‑1”，7–37必须进入必需正靶集合。只有在明确做7–36NH₂肽型态专一时，7–37才作为交叉反应挑战。
化学表达缺口：常规 AlphaFold 蛋白序列输入并不会天然把“C 端羧酰胺”和“游离羧酸”当成两个型态。主清单必须保留 c_terminal_mod: amide；没有显式建模酰胺化的结果只能叫“骨架层面验证”。
03 / DATA

数据从哪里来，怎样落到文件

公共库提供结构、序列和一般性相互作用先验；内部实验提供型态选择性的真实标签。

STRUCTURE · PRIMARY

RCSB PDB / wwPDB

下载实验结构和 NMR 模型，权威存档使用 PDBx/mmCIF；PDB 只做旧工具兼容。1D0R 提供20个NMR构象，6X18是活性型受体复合物；9IVG是未加入LSN3318839的9–36–GLP‑1R–Gs结合态，9IVM才是含LSN3318839的比较态。二者都不是游离9–36的溶液构象。

官方入口 ↗
SEQUENCE · ANNOTATION

UniProtKB

核对前胰高血糖素原、成熟肽区间、物种和注释。REST API 可输出 FASTA、JSON、TSV；前体 FASTA 不能直接当作 30 aa 成熟肽。

API 格式 ↗
VHH · SCAFFOLD

SAbDab / SAbPred

筛选结构完整的单域抗体框架，使用 ANARCI 统一编号并建立 CDR/框架掩码。批量、再分发和商业使用需核对站点条款。

SAbDab ↗
PEPTIDE COMPLEX

PROPEDIA

提供蛋白–肽复合物，用于界面统计或轻量预训练。重复条目很多，必须使用聚类中心并按肽、蛋白和三维界面去重。

PROPEDIA ↗
AFFINITY · AUXILIARY

SKEMPI / BindingDB

可辅助学习一般突变—亲和力规律，但不是 GLP‑1 型态选择性数据；KD、Ki、IC₅₀ 也不能混成同一标签。

LABEL · PROJECT TRUTH

内部实验数据

同一候选对正负靶的 KD、kon、koff、回收率、表达、聚集和失败样本都要回流。失败是负标签，不是垃圾。

schema_version: "1.0"
primary_key: [target_state_id]
enums:
  role: [required_positive, negative, cross_reactivity_challenge]
  n_terminus: [free_alpha_amino, acetylated, other]
  c_terminal_mod: [amide, free_carboxylate, other]
constraints:
  - "length == len(sequence)"
  - "biological_index_end - biological_index_start + 1 == length"
  - "tool_index_start == 1"
required_fields: [target_state_id, sequence, length, role, n_terminus, c_terminal_mod, biological_index_start, biological_index_end, tool_index_start, peptide_batch_id, peptidoform_ref]

04 / ARCHITECTURE

两个设计空间，不混为一谈

VHH 需要固定免疫球蛋白框架；BindCraft/RFdiffusion 主要解决从头小蛋白。它们共享评价层，生成约束不同。

BRANCH A · CONSTRAINED

VHH 受限设计

保留可表达、可溶并有结构证据的框架，只开放指定 位点。

A1
框架筛选与标准编号SAbDab/SAbPred → ANARCI；排除结构缺失和明显聚集框架。
A2
先建立复合骨架/姿势集合用多 seed 复合物预测与受约束对接产生 VHH–GLP‑1 姿势；只保留让 H7/A8 面向 CDR 的多样骨架。
A3
定义设计掩码固定肽、框架、核心和二硫键；只开放选定 CDR 位点，长度变体分开建模。
A4
结构条件序列设计ProteinMPNN/Rosetta 在每个复合骨架上采样，加入禁用残基与电荷约束。
A5
单体与复合物双验证同时检查 VHH 折叠、正靶、负靶、姿势依赖和跨 seed 一致性。
BRANCH B · DE NOVO

从头小型捕获蛋白

在指定热点周围生成新的蛋白骨架，再为骨架设计序列。

B1
热点与几何先验以 His⁷/Ala⁸及自由 N 端为引导，不硬编码唯一姿势。
B2
骨架生成BindCraft 用 AF2 可微优化；RFdiffusion 用 SE(3) 等变去噪扩散。
B3
序列化与复折叠ProteinMPNN 产生多序列；未参与生成的预测器做正交复核。
B4
显式负靶后筛原版 BindCraft 不是型态选择性平台，需自建负靶对比层。
DE NOVO PIPELINE

BindCraft

AF2 反向传播优化候选，再接 MPNN、AF2 复验和 PyRosetta。适合快速从头生成，不原生解决 peptidoform 选择性。

OUTPUTPDB、序列、CSV

06 / LOSS

损失函数：三层概念分开

基础模型训练损失、单靶设计时损失、生成后多目标排序不是同一件事。

① ProteinMPNN 训练/评分：序列负对数似然

Lseq = −(1/|D|) Σi∈D log pθ(ai | Xbackbone, a<i, afixed)

X 是骨架，D 是设计位点。低分表示序列更符合骨架统计规律，不表示一定结合 GLP‑1。

② 柔性正靶与最坏负靶的选择性

Lsel = softplus[(mE + E+required − E−risk)/τ]

能量 E 越小越好：同一正靶构象内允许存在一个可结合状态；多个必需正靶取最坏型态；负靶取最容易误结合的构象。mE是能量单位margin。

③ 项目多目标设计函数

Ltotal = λfoldLfold + λposLpos + λselLsel + λNLN-term + λdevLdev + λuncLunc + λdivLdiv

先统一方向并稳健归一化，再校准 λ。原始 pLDDT、Å、能量和疏水比例不能直接相加。

④ 轻量排序器：精确值、删失值和成对排序

pKD = −log₁₀(KD/1 M)
Laff = λexactΣi∈UHuber(μi,yi) + λcensΣi∈C−log P(li<Yi≤ui|μi,σg(i))
L = Laff + λranksoftplus[(mpK−(pK̂D,+−pK̂D,−))/τ]

MLP只预测μ；σg(i)是按assay/条件分层、仅用训练折残差校准并随后冻结的噪声尺度，不是未受监督的逐样本σ头。单侧删失用−∞/+∞端点；mpK=log₁₀(SFtarget)。

⑤ N 端原子级约束

Lcontact = (1−cH7)² + (1−cA8)²，c∈[0,1]
LN-term = −log(CN+ε) + λHLcontact + λUUN

CN∈(0,1] 是自由 α‑氨基几何/极性满足度；H7与A8各有独立软接触，避免“只碰H7两次”也通过。同时加入删去H7/A8、封闭N端和前加残基等结构性负样本。

⑥ 实验选择性与自由能差

SF = KD,negative/KD,positive
ΔΔGsel = ΔG°negative − ΔG°positive = RT ln(SF)

298 K 时 10×、100×、1000×选择性分别约为 1.36、2.73、4.09 kcal·mol⁻¹。所有 KD必须同条件、同拟合规则。

BindCraft 的“loss”是设计时优化：冻结 AF2 权重，对候选序列概率反向传播。官方配置包含 pLDDT、链内/链间 PAE、接触、ipTM、回转半径等项；这些不是重新训练 AlphaFold，也不能把默认权重当成通用真理。

Syield = Yieldpos / Yieldneg

负靶低于定量下限时不得置0或报告∞；应给选择性下界、置信区间和删失方向，并传播两侧定量不确定度。

08 / TRAINING

训练计划：什么时候才值得动模型

先获得可信标签，再增加模型自由度。数据不足时微调大模型会放大泄漏与过拟合。

PHASE 0 · 0 LABELS

冻结基础模型

版本锁定、推理和设计时优化；建立正负靶结构集合；验证数据契约和可复现运行。

PHASE 1 · PILOT

20–40 个差异化候选

覆盖多个结构簇，不只测最高分；收集表达失败、删失值和模型分歧，校准计算指标。

PHASE 2 · RERANKER

约 50–2,000 个成对测量

线性/Elastic Net、Gaussian Process、XGBoost 或小型 MLP；核心预测pKD,+与pKD,−。只有另有表达标签、mask和损失时才增加表达头。

PHASE 3 · CONTROLLED TUNE

数千个独立高质量标签

才评估结构图编码器、LoRA/adapter 或专用 affinity head；仍不建议从头训练 AF2/AF3/RFdiffusion。

正确的数据切分

同一骨架的近似突变体不能随机散到训练与测试。至少按 scaffold_family_id + generation_parent_backbone_id + sequence_cluster_id 分组；再按三维界面聚类，最后保留时间外盲测。

主动学习不是只选最高分

下一批价值可写为“预期提升 × 不确定性 × 与已测候选距离”，再加实验容量和家族配额。这样既寻找好候选，也能纠正模型。
