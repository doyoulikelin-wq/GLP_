# Shared 一次性代码

这里保存仓库级迁移、索引和一次性报告准备脚本。它们不得被两条模型流水线导入。

- `构建资源索引_20260826.py`：读取原项目工作区与仓库中的精选输入，生成三份资源索引和 BindCraft PDB 面板逐文件清单；不会下载、移动或删除数据。
- `构建仓库文件映射_20260826.py`：生成 Git 工作树逐文件来源、大小和 SHA-256 映射。
- `构建项目总览报告_20260826.py`：从会话索引、资源表和路线状态构建项目总览报告 artifact。
- `构建本地资产树清单_20260826.py`：对 Git 外资产生成整理前后完整树清单，并可逐行验证两阶段是否完全一致。
- `整理本地工作区_20260826.py`：非破坏式本地迁移工具；默认 dry-run，只有 `--apply` 才移动资产并创建兼容链接。

`整理本地工作区_20260826.py` 已于 2026-08-26 对当前工作区执行。它是有前置条件的一次性迁移脚本，不应在已整理目录上重复执行；后续以 `workspace://manifests/local_assets_20260826/` 的回执为准。
