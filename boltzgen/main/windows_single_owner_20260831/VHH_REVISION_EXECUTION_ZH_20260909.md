## 关键解释更正

项目终点是活性 `GLP-1(7–36)NH₂` 相对截短 `GLP-1(9–36)NH₂` 的识别偏好。
人工定位的参考构象不是实验复合物；对它的 RMSD 只能衡量姿态自洽性，
不能直接推断脱离目标、不能结合或选择性。历史 T11/T12 RMSD 数值不变。

T12 将 target 和 framework 分成两个模板槽，不包含两者相对位置几何。
当前 folding checkpoint 不消费 `binding_type` 条件分支；输入含 His/Ala 标记
不等于复折叠被该位点约束。自由复核与条件化设计分开，不开启未训练的条件分支。

## 六项改进的交付边界

| 改进 | 本轮软件或规则交付 | 科学上仍需完成 |
|---|---|---|
| 评价回到端部机制 | 端部接触、界面接触图、重复稳定性和重叠提示；RMSD 保留为辅助 | 接触不是结合或选择性真值 |
| 明确模型输入的实际作用 | 区分模板可见性、位点元数据和权重实际消费分支 | 不能把强制保持姿态作为独立验证 |
| 加入已知对照 | 先做 CPU 几何自检，再做有界自由复折叠；两者分别记状态 | 已知结构可能存在训练集记忆；通过不保证新 GLP-1 候选可预测 |
| 活性／截短配对 | 同一候选身份绑定、匹配输入条件、来源分组及端部化学检查 | 新候选不得继承旧候选的多状态结果；未建模修饰须明示 |
| 候选多样性与风险 | 校准后的小型多框架／识别环／姿态试点；可开发性代理描述 | 不保证表达、稳定性或选择性；未生成不写成已完成 |
| 精简执行 | 每轮一个问题、明确预算和停止条件；输入只读、新目录、增量验证 | 不重复全树审计；实际使用的权重仍需运行前后完整性确认 |

4 个设计构象的接触重心描述均在靶肽 C 端一段，His7/Ala8 均未接触。
自由复折叠的 20 次预测中：任意 target–CDR 接触 20/20，His7 接触 2/20，
Ala8 接触 2/20，同时接触两者 1/20；持续全部 5 次双端部接触的候选为 0/4。
没有 target–CDR 小于 1.5 Å 的距离提示，但不能据此声称整个 VHH 没有近距离冲突。
这 20 次不是 20 个独立分子，也不能与 T11/T12 作为严格匹配试验比较。
新设计的 YAML 已有端部 `binding: 1..2` 标记；结果提示该标记没有带来稳定的端部接触，
不能仅从结果断言生成 checkpoint 完全忽略该分支，亦不能把它当成硬几何约束。

姿态比较在运行前要求：生成后的目标骨架中心经刚体对齐 RMSD ≤0.001 Å。
实际相对固定首候选，另外 3 个候选均超出该值；独立 CIF/NPZ 交叉检查显示
6 对候选间偏差约为 0.070–0.106 Å。偏差已存在于生成阶段，逆折叠前后目标几何
基本一致。这是真实、轻微的靶肽形变，说明本轮“目标几乎完全相同”的比较前提不适用，
不是原子映射错误，也不是生物学失败。
原阈值未放宽；姿态类别数量为 `null`（不可评估），不是 0 类、没有多样性或成功。

## 下一步的明确问题

1. 核查生成阶段的端部条件是否真正进入已训练分支、特征是否符合预期，并检查初始相对布局；
   已有 YAML 标记不是条件有效的证据，不开启未训练的开关。

   使用本轮数据只能算事后方法开发，不能倒改本轮门槛并宣称原方案通过。

   才使用已完成的配对运行器检查同一组候选的活性／截短差异。

端部酰胺化、游离氨基的原子级表示仍未验证；当前只允许计算假说，不允许亲和力或选择性结论。
