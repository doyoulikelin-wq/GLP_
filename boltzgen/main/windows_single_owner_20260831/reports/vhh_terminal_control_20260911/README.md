> **2026-09-13 更正（历史记录保留）**：下文旧表的“生成时”实际取自序列改写后的 IF 输入，不是原始生成 CIF。该 IF 输入的设计侧链包含零坐标占位，CDR 重原子接触应为“不可评价”，不是 0 次接触。重新读取原始生成 CIF 后，A/B/C 双端接触分别为 0/2、0/2、1/2；自由复折叠的 1/10、0/10、0/10 不受本项更正影响。旧 C 组初始距离段落也属于 IF 输入，不能用于原始生成或化学机制结论。以 [本轮更正与处理记录](../vhh_four_blockers_20260913/README.md) 为当前解释；原始 JSON、失败收据和下方历史叙述不覆写。

## 结论

输入与严格评价的兼容性门已落实，本轮 6 条候选及 30 次自由复折叠全部可评价，
不需要局部原子降级。但没有候选在全部 5 次自由复折叠中持续接触 His7 和 Ala8。
本次是计算探索，不是结合或选择性验证。

| 条件（同一 7XL0 骨架） | 生成时双端接触／候选 | 自由复折叠双端接触／预测 | 全部 5 次保持双端接触／候选 |
|---|---:|---:|---:|
| A：不指定结合位置 | 0/2 | 1/10 | 0/2 |
| B：提示 His7/Ala8 | 0/2 | 0/10 | 0/2 |
| C：提示 His7/Ala8，其他位置设非结合软条件 | 0/2 | 0/10 | 0/2 |

双端接触：His7、Ala8 分别至少一个重原子距 CDR 重原子不超过 4.5 Å，定义未变。
五次预测属于同一候选的重复，不能当作五条独立分子；三组不共享完整随机数链，
每组仅两条候选，不能因 A 的 1/10 就判断 A 优于 B/C。六条序列互不相同，
全部保留；旧过滤通过数不是本表分母。

C 组初始生成中 His7 距 CDR 为 4.57–5.00 Å、Ala8 为 6.83–7.02 Å，
在本次样本中比 A/B 更接近端部，但仍未达到预设双接触阈值；
自由复折叠没有保持双接触。此为观察，不证明条件有效或模型无效。
自由复折叠的姿态 V2 均不适用，仍记 N/A，不转成零分或不能结合。

## 具体修复了什么

- 在 GPU 前，用实际解析的生成表示和规范来源全原子表示检查完整性。
  7XL0、6APO 通过；8IM0 因 16 个缺失框架原子拒绝，未人为补原子或修改旧失败。
- 选完整 7XL0 做三条件小对照，每组 2 条、每条 5 次；CPU 验证标签确实进入输入，
  隔离诊断中每个样本 78 个非 binding 张量一致。
- 三组统一关闭旧 binding-site 筛选，缺失的旧位点 RMSD 指标允许为“不适用”，
  若存在仍检查有限值。没有补零，没有降低原 E 全原子评价要求。
- 每组实际输出都检查完整原子、目标和条件标签，最终逐位核对 91 个非 CDR 框架残基。
  本轮全 6 条框架身份一致，全部生成及复折叠可严格评价。

## 如实保留的运行问题

A 的 GPU 和分析阶段完成后，旧输出检查器仍把一个可选位点 RMSD 列当作必填，
导致首次流程失败。这是运行前遗漏的下游兼容性要求，不是 GPU 生成失败。
修复后仅做 A 的 CPU 补验证，保留原失败收据及输出；只执行尚未启动的 B/C，
不重跑 A，不增加候选，不改变条件或阈值。不能称为首次无错误跑完。

从首次 GPU 尝试开始至 C 组完成为 1328.73 秒（22 分 8.73 秒），
包含中途修复空档；原 1800 秒截止未延长。详细分阶段耗时另见时间记录。
403 项软件测试通过（28.92 秒，1 个既有依赖警告）。
这不是生物学验证，也不是全仓政策检查通过；全仓仍有历史说明／缓存问题。

在这个 22 分 8.73 秒实验窗口内，已单项记录的阶段命令占 40.64%，
修复、CPU 补验、测试和冻结发布空档占 56.33%，其余未单项计时执行开销占 3.03%。
阶段命令含模型加载／CPU 准备，不是纯 GPU 内核时间；现有记录不能得出哈希占比。

## 如何复现／审计

CPU 入口为 scripts/preflight_vhh_evaluator_compatibility.py 和
scripts/prepare_vhh_terminal_controls.py；原运行入口为 scripts/run_vhh_terminal_controls.py。
对应文件均在本所有者目录。本次续跑专用脚本
scripts/resume_vhh_terminal_controls.py 只接受本次已知 A 失败和原绝对截止，
现在是历史复现证据，不是启动新一轮的通用命令。

最终汇总入口为 scripts/summarize_vhh_terminal_continuation.py。
研究生可在本机用新的输出目录，对已完成的 continuation INDEX 再做 CPU 汇总；
不要覆盖原目录、修改记录或直接再次启动 GPU。

下一步建议先从现有结构复核“端部软条件为何没有转成稳定双端接触”，再决定是否另立
新预算／新方案。活性型与截短型选择性、NH2 原子化学和实验结合仍未解决；
不自动扩骨架、不自动转 BindCraft。
