# VHH 端部识别不稳定：进一步研究结果

本轮复用上一轮全部 18 个预测，未启动 GPU、生成新序列或加载权重。
研究重点从“再改几个氨基酸”转为“究竟哪里发生了变化”。

## 新发现

### 1. 多数没有完全离开靶标，而是接触位置不符合目标

18 次预测中只有 2 次满足原定 His7/Ala8 双端接触。其余 16 次可以互斥分为：

- 15 次有识别环（CDR）接触 GLP-1 中段或 C 端区域；不是稳定抓住所需 N 端。
- 1 次只有 VHH 框架接触，没有 CDR 接触。
- 没有一次是整个 VHH 都不存在 4.5 Å 内接触。

所有 18 次都有框架接触，但它不能冒充识别环接触。上述是预测结构的距离关系，
不是已经发生实验结合，更不是选择性证明。

### 2. 框架自身较稳定，相对位置和识别环变化更值得关注

将 VHH 框架各自单独对齐原始设计，框架 C-alpha RMSD 为 0.659–1.041 Å，
总体中位数 0.848 Å。这不支持把本轮问题简单归结为“框架整体塌了”。
三个组的完整 CDR RMSD 中位数分别为 2.292、2.441、4.994 Å；最后一组是局部重建。
这只是小样本描述，不能单独归因为某种编辑方法。

把靶肽中央对齐到同一参考后，VHH 相对原设计位置差异很大。此处参考是生成的
原设计，不是实验 VHH 结合结构，所以不能把这个偏差叫“实验结合位置误差”。
它同时含位置、方向和残余形变，不是可以相加的因果贡献。

### 3. 两次端部命中都伴随靶肽明显改变构象

两次命中的靶肽整体 C-alpha RMSD 分别为 12.018、10.528 Å，端部 His/Ala 的
C-alpha RMSD 分别为 24.344、22.154 Å。换用更短的中央对齐区间，明显偏离的
判断不变。因此，它们不能直接证明原设计构象下实现了端部识别。

做了一个只用于诊断的坐标替换：保持每个预测的 VHH 不动，将原靶肽按中央结构
对齐放回。双端接触变为 0/18，包括原先两次命中都消失；没有救回另外 16 次。
这不是新预测，也没有能量松弛，还会产生几何碰撞，不能当作物理有效结构或因果证明。

重要限定：原始目标文件来自受体结合态 [6X18](https://www.rcsb.org/structure/6X18)。
不能把这一种构象当作游离 GLP-1 唯一真值。[GLP-1 的 NMR 原始研究](https://doi.org/10.1002/mrc.880)
及其 [1D0R 结构](https://www.rcsb.org/structure/1D0R)表明构象与溶剂条件有关；1D0R 是
TFE/水条件，不是生理溶液态的直接替代。**变形不自动等于错误；构象保真和端部接触
必须分开报告。**

### 4. 五位窗口不是所有端部接触的共同来源

两次双端接触都由 CDR3 提供。原始组那一次来自 VHH 第 100/101 位，在编辑窗口
106–110 之外；局部重建组那一次则由窗口内的 107/108/109 位参与。
这说明局部窗口能参与接触，但尚未提供稳定性证据，不足以据此扩增该窗口的候选。

界面置信度 ipTM 范围为 0.141–0.332，两次端部命中分别为 0.291、0.174。
它是界面结构置信度指标，不是结合概率或亲和力；本轮不另加一个事后分数阈值。
定义见 [Boltz 官方预测说明](https://github.com/jwohlwend/boltz/blob/main/docs/prediction.md)。

## 对项目的实际调整

1. 新增并验证两套 CPU 诊断脚本：分别检查目标/框架/识别环/相对姿态，以及接触位于
   哪个 CDR、靶肽哪一段。后续结果可用相同流程复算，不再只报双端接触次数。
2. 保留原有 4.5 Å 接触终点和全部负结果；本轮没有回头修改“通过标准”。
3. 下一研究重点是目标构象敏感性和端部定位，暂不扩骨架、不追加大批局部改写。
   必须分别讨论“保持参考构象的设计自洽性”和“允许柔性目标的端部识别”，不能混成
   一个成功率。受约束姿态不能冒充无提示自由识别。

## 下一条技术路线的兼容性检查

独立 Boltz 官方文档提供 `templates.force` 和 `threshold`，使用势能限制偏离，
并不意味着绝对刚性固定。但本机是 BoltzGen 0.3.2，不是独立 Boltz：

- 本机未安装独立 `boltz`；现有包不接受官网这套强模板输入语法，CPU 解析实测拒绝。
- 在检查的本地接口/采样实现中，没有可直接启用的对应模板势能流程。
- 另装独立 Boltz 后能否复用当前权重尚未严格验证，不能因文件名相似就宣布兼容。

因此没有把官网参数硬塞进原流程，也没有改动当前环境。后续若走这条路线，先建立
隔离的兼容性分支，核实版本、输入解析及 checkpoint 严格加载，再做有限的
“有/无目标构象约束”对照；该对照依然不是结合验证。

## 证据与完成状态

全部 18 个预测保留。主诊断与独立 SciPy 实现的 90 项结构测量最大差异为
3.09e-6 Å；36 项人工替换距离最大差异约 1.07e-14 Å。主对齐区间和较短敏感性
区间下，人工替换后的双端接触均为 0/18。相关测试 547 项通过，32.36 秒。

两项主 CPU 分析实际各约 0.6 秒，其余时间用于方法核对、独立复算、软件能力检查、
测试和记录。没有进行模型权重大规模哈希扫描，没有新增 GPU 推理。
