# VHH 局部编辑小试报告（2026-09-13）

## 结论

本地局部编辑和统一复核流程已经跑通，但这轮没有证明端部识别获得稳定改善。
这不是 Boltz 云端 API 的测试，而是用本机 BoltzGen 0.3.2 尝试相同编辑思路。
没有上传云端、训练模型、扩展骨架或执行蛋白拼接。

## 实际做了什么

保留原先 C 组全部两个原始候选，确定性枚举 18 个可选窗口后，选定第三条识别环
（CDR3）的 VHH 第 106–110 位，只允许这五个位置编辑，不改变长度。每个原始候选
分别进入保持原样、只改序列、局部重建三种流程，每项做三次不固定 VHH 原结合姿态
的自由复核，共六项任务、18 个预测结构。主要评分仍看全部三个 CDR。

局部编辑实际发生的情况：

- 只改序列：两次均返回原序列，变化数都是 0。实际 CPU 检查证实五个位置的序列
  身份均正确遮罩，未发现直接复制原序列的范围错误；应保留为合法无变更输出。
- 局部重建：两个候选各改变 1 个氨基酸，所有窗口外的序列、框架身份和长度保留。
  窗外骨架对齐 RMSD 分别为 0.184、0.113 Å，最大位移约 1.55、1.50 Å；
  因此是保留上下文的软约束编辑，不能称窗口外坐标绝对锁死。
- 实际是六项评估任务、四条不同最终序列，不是六条不同新分子。

## 结果

同时靠近 His7 和 Ala8 是这次关注的端部几何指标，阈值均为重原子距离不超过
4.5 Å。每组的六次是两个候选各三次随机预测，不是六个独立候选。

| 处理方式 | 与靶标任意位置有 CDR 接触 | 同时接触两个端部位点 | 三次均保持双端接触的候选 |
|---|---:|---:|---:|
| 保持原样 | 5/6 | 1/6 | 0/2 |
| 只改局部序列 | 6/6 | 0/6 | 0/2 |
| 局部重建 | 6/6 | 1/6 | 0/2 |

局部重建的候选 1 在一次预测中达到 His7 4.243 Å、Ala8 2.237 Å；另外两次未达到
双端接触。它与原始组一样仅有一次命中，尚不能称为提升。两条原始/序列改写候选
的序列实际上相同，1/6 与 0/6 的差异不能解释成序列改写使其变差。

局部重建另一个未命中端部的结构出现 1.097 Å 的异常近接触提示，需要保留为
几何质量风险；这是粗诊断，不是按原子类型判定的正式碰撞评分。不能只凭一般接触
增加，就宣布端部特异识别改善。

## 完整性、时间和边界

四个编辑步骤及统一自由复核全部正常完成；没有自动重试。运行器总墙钟为
228.145 秒（约 3 分 48 秒），其中两次序列步骤共 22.750 秒、两次重建步骤共
82.764 秒、自由复核步骤 108.685 秒，其余约 13.946 秒是校验、CPU 准备、评分等。
这些是步骤进程墙钟，含启动和加载，不能写成纯 GPU 内核时间，也不能将剩余时间
全部归为哈希计算。代码开发、测试与报告整理在运行器时间之外。

18 个结构全部通过输出闭合、序列范围、原子映射、完整重原子、有限坐标和占位
检查；独立计算没有调用原接触评分函数，重算结果一致。实际使用的四项资产运行
前后未变。最终冻结代码相关测试 520 项通过，30.11 秒。

本轮保留的重要限制：

- 两套现成编辑流程的权重和默认设置不同，序列改写禁止新增 Cys，局部重建没有
  同等显式限制；虽然本轮所有窗口结果均不含 Cys，仍不是严格单变量方法比较。
- 短肽评价沿用已有真实 9NK9 两次恢复校准，不等于证明 GLP-1 结合。
- 尚未原子级验证端部酰胺化、质子化及电荷，也没有湿实验亲和力或选择性数据。

## 项目判断

有用的是“保留大部分分子、只允许局部编辑”的工具能力；本轮尚未证实它能解决
我们的端部识别不稳定问题。保留局部重建作为后续研究工具，但不升级为主线大规模
筛选，也不因这次小试迁移到云端 API。若继续，首先需要解决可重复的端部定位与
评价；不应仅凭这次单次命中继续放大候选数量。本轮至此结束，没有启动下一批。
