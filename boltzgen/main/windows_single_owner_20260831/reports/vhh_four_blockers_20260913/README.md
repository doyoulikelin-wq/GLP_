# VHH 四项问题：修正结果与剩余阻碍（2026-09-13）

## 结论

四项问题的工程修正与有界计算已完成；**端部稳定识别和真实端基化学仍未解决，不能称为生物学成功**。本轮没有训练、没有更换权重、没有转 BindCraft。

| 问题 | 本轮完成 | 还没有得到什么 |
|---|---|---|
| 端部识别定位 | 分开原始生成、序列改写、自由复核；纠正占位侧链误判 | 稳定识别 His7/Ala8 |
| 软条件/序列改写 | 全部两个 C 组来源，原始/改写序列共 8 次自由复核 | 软条件保证成功或序列方案优越的证据 |
| 短肽评价 | 已知 9NK9 界面两次均达到预设恢复门槛 | 广泛可靠性、生物阴性识别、GLP-1 特异性 |
| 同候选活性/截短 | 6 候选×2 状态×2 次，24 次完成；编号/标签修正 | C端酰胺/N端电荷的原子级证实、真实选择性 |

CDR 指纳米抗体的三个识别环；双端接触指 His7 和 Ala8 分别距 CDR 重原子不超过 4.5 Å。

## 重要更正：此前的“生成阶段全失败”不成立

旧汇总的 generated 字段取自 IF（序列改写后）输入，不是原始生成 CIF。IF writer 会放置零坐标侧链占位；这类输入的 CDR 重原子接触应为 **N/A，不能写成 0**。新诊断拒绝将其用于完整结构接触结论。

| 原条件 | 真正原始生成双端接触 | 序列改写输入 | 旧自由复核双端接触 |
|---|---:|---|---:|
| A 无端部提示 | 0/2 | 不可评价 | 1/10 |
| B 提示 His7/Ala8 | 0/2 | 不可评价 | 0/10 |
| C 提示 His7/Ala8、其余设非结合软条件 | 1/2 | 不可评价 | 0/10 |

原始/改写骨架位置近乎不变，但 CDR 序列有变化，IF 侧链未形成完整构象。既不能说原始生成完全未找到端部，也不能据此认定 IF 破坏了结合。历史数据原样保留，原报告顶部加更正。

## 已知短肽校准：通过，但有范围

使用 [9NK9 实验结构](https://www.rcsb.org/structure/9NK9)：完整已建模 10 aa 肽，VHH 用连续的 118 aa 已建模部分；沉积序列中未建模的 14 aa 末端明确省略。保留真实二硫键，没有补缺失原子。来源为 [JBC 原始论文](https://pubmed.ncbi.nlm.nih.gov/40409557/)。

只给目标肽内部模板，不给原生跨链相对位置。预先固定恢复门槛为：目标对齐后 VHH Cα RMSD ≤5 Å，原生重原子残基对接触召回 ≥0.30，两次均满足。

- 第1次：1.9808 Å，找回 30/38 对接触（78.9%）。
- 第2次：2.1882 Å，找回 28/38 对接触（73.7%）。

这是一个已知正对照的恢复检查，不是 GLP-1 结合验证；模型训练集是否见过它未知，没有生物阴性对照。不能把位移100 Å的几何检查称为生物阴性。

## 原始序列还是改写序列？

使用整个 C 组两个来源，不只挑已有双端接触的一条；每来源两版序列，各两次自由复核。四任务使用同一目标几何，无 VHH 模板、无 binding 提示，并验证输入中的 VHH 平移不改变可见模板。

| 序列来源 | 任意目标位置与CDR接触 | His7/Ala8双端接触 | 两次均双端接触的来源 |
|---|---:|---:|---:|
| 原始生成序列 | 4/4 | 0/4 | 0/2 |
| 序列改写后 | 0/4 | 0/4 | 0/2 |

保留原始序列在这个小样本中改善了一般 CDR 接触，但没有实现端部双接触。两条来源、嵌套随机重复不能证明方案优越、改写是唯一原因或真实结合；不把某一端的接触转称双端识别。

## 活性/截短比较完成到哪一步

同一批六条 IF 候选完成 24 次预测。两状态均有 3/6 候选在各自两次预测中与 CDR 保持某处目标接触；活性型中两次均双端接触的候选是 0/6。这不是两状态“结合强度相等”的证据。

修复了删除 His/Ala 后残基编号 3..30 与实体序列 1..28 不一致的问题；同候选 VHH 序列、共享目标坐标及原子映射保持，被删除的正标签不转移到 Glu9。截短型不存在 His/Ala，其端部接触记“不适用”，不是测量到零。

当前标准氨基酸路径没有证实 C 端酰胺及自由 N 端电荷。ARG 的 NH2 是侧链胍基氮，不能冒充 C 端酰胺。历史状态名中的 NH2 只是旧标签。本轮只支持**几何匹配的删除对照**，不使用原始 iPTM 差值宣称选择性。

## 现在真正剩下的工作

1. 端部界面仍是科研主阻碍。暂不扩大骨架和随机采样；保留原始序列分支作为下一轮候选策略之一，而不是把它升级为已证实最优方案。

3. 后续仍需独立短肽/阴性校准和真实实验；本轮计算不支持亲和力、选择性、成药性或临床结论。
