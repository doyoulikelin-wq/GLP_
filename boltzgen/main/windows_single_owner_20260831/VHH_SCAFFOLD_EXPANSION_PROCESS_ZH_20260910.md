## 固定边界

- CPU 备选登记 4–6 个；新 GPU 试点最多 3 个骨架（保留 7XL0、6APO，加 1 个）。
- 本轮选择每骨架 2 个新候选、每候选 5 次自由预测：共 6 个候选／30 次自由预测。
  这是最小探索预算，不是统计充分性声明；未满足准备条件时不运行。
- 如启动，GPU 总墙钟上限 1800 秒，同一时间只有一个主任务，无自动重试或扩增。
- 不训练、改权重或启用未训练条件分支；原始输入、失败和旧结果不覆盖。
- 2026-09-09 的 0.001 Å 姿态比较规则及其 BLOCKED 结论原样保留。
  新评价方法单独版本；旧数据上的应用只算事后方法开发，不给旧试点补发通过。
- GitHub 只提交代码、规则和脱敏汇总；原始结构、候选序列、完整日志在本地新目录。

本轮不重建这些侧链，不把输入就绪等同于全原子完整或生物学可开发。

生成机制核查纠正了一个可能误解：生成模型确实读取端部软条件，而自由复折叠模型
不读取该分支。其余 28 个 target token 为 UNSPECIFIED，非 NOT_BINDING。
跨 target/framework 的可见距离条件为零；平移 VHH 后该距离通道不变，
扩散由随机噪声开始，不能假定简单移动输入骨架能锁住最终结合姿态。
这不证明全网络对所有输入坐标均不敏感，也没有建立之前 C 端接触偏向的完整因果解释。
因此本轮保持三组相同生成条件，测试框架探索价值，不宣称已修复模型的端部服从性。

## 待完成的继续条件

1. 备选骨架的来源、实际残基映射、CDR 长度和结构完整性均有可复查记录。
2. 新增框架与至少一个原骨架具有匹配的 CDR 长度；不能把结构副本当成新增骨架。
3. 端部条件从 YAML 到实际模型特征／已训练分支的路径得到核查；仅写入标记不算生效证明。
4. 新姿态方法通过刚体不变性、轻微形变、明显形变、局部端部异常和退化结构测试。
5. 冻结新计划与实现摘要后才能运行；旧阶段门不被修改为通过。
