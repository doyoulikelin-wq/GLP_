## T7：LOCAL_ENV_ACCEPTANCE

复用 T2 当前可运行环境，执行一次短检查：

- `nvidia-smi` 能看到 5070 Ti，且没有进行中的冲突 GPU 主任务；
- Python 能导入 `torch` 和 BoltzGen，`torch.cuda.is_available()` 为真；
- CUDA 张量和 BF16（16 位脑浮点数）最小计算通过；
- cuEquivariance 原生 GPU 算子的最小前向/反向检查通过；
- 实际要运行的工作盘有足够空间；空间预算按本轮实际规模估算，不再固定要求 250 GiB；
- 实际使用的权重和分子字典文件在运行前可读，记录文件大小，并在 Windows
  本机将它们的 SHA-256 与交接包清单核对一次。这只是检查约 6 GB 运行资产有无
  复制损坏，不是冻结环境或 Mac 签发。正式推理运行器仍应在运行前后核对权重。

通过写 `LOCAL_ENV_READY`，失败写清错误并修复后重试。这里不冻结环境合同、不建第二套环境、
不等待 Mac，也不把结果称为正式 G1。
