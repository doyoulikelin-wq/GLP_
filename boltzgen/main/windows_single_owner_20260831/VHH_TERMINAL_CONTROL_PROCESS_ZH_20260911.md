## 本轮任务与边界

本轮选择严格全原子评价，新增运行前 CPU 检查；不通过补标缺失原子来放行输入。
不修改 2026-09-10 的冻结代码、失败结果及事后局部诊断。
不增加骨架，不训练或改写权重，不自动重试、不转 BindCraft。

## 运行前固定的研究问题

在同一个来源完整的 7XL0 骨架、相同目标、相同 CDR 设计范围、
相同 adherence 权重与预算下，改变端部条件，观察生成与自由复折叠的端部接触。

| 条件 | His7/Ala8 | 目标其余 28 个残基 |
|---|---|---|
| A：无位置提示 | 未指定 | 未指定 |
| B：仅提示端部 | BINDING | 未指定 |
| C：端部提示及其余位置排除 | BINDING | NOT_BINDING |

NOT_BINDING 是模型的软条件，不是硬性禁止接触。
固定预算为每组 2 条候选、每条 5 次自由复折叠，共 6 条候选、30 次预测；
单个 GPU 主任务串行执行，GPU 工作流硬上限 1800 秒。
无论结果好坏均保留所有候选及其分母；软件运行成功不等于真实结合。

主要描述为：生成构象双端部接触、自由复折叠双端部接触次数、
每候选全部 5 次保持双端部接触。姿态 V2 仅作有适用范围的补充诊断。
不以旧过滤幸存数代替这三个指标，不用姿态 N/A 充当零类或不能结合。

## 运行前发现并修复的问题

1. 实际 CPU 双表示检查：7XL0、6APO 全原子兼容；8IM0 的生成表示及
   规范源表示均检出 16 个缺失框架原子，返回拒绝。检查没有修改源坐标、解析标记或旧 E 评价器。
2. 输入合格不保证尚未生成的 CDR 也合格。新运行器在每组结束后，立即对真实生成结构
   和 5 次复折叠运行原严格评价；出现不兼容就停止，不继续消耗后续组 GPU。
3. CPU 证据核对同时检查三条件的真实解析／掩码标签、特征快照摘要、原始四文件和上游
   相关源码摘要。仅有 READY 标签、同长度骨架或未变的 JSON 文件不构成放行依据。
4. A 组无指定结合位点，上游分析不输出旧的位点 RMSD 筛选列；旧筛选器访问该列会
   `KeyError`。该路径已用 A 组真实 CPU 特征和现有筛选逻辑复现，尚未消耗 GPU。
   新的执行适配器对 **三组统一关闭旧 binding-site 筛选**，
   同时将配置验收要求固定为关闭；其余执行、锁、超时、权重校验和收据流程保留。
   端部接触仍由独立严格 E 指标统一计算，不给缺列补零、不改原始旧脚本。

CPU 固定随机环境下，三组每个样本的 78 个非 binding 张量一致；这只支持
输入条件隔离检查，不证明未固定随机源的实际 GPU 派生张量或结果也相同。
