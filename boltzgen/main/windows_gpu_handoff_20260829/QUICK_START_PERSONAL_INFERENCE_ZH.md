# Windows 个人电脑：一条命令开始 VHH 推理

这个入口只做一件事：加载包内已有的 BoltzGen `v0.3.2` 权重，针对公开的
GLP-1 输入完成一次真实的 VHH 候选生成和筛选。

它不会修改模型权重，也不会把计算结果写成“实验成功”。第一次运行会自动检查交接包、
复制到 WSL2 的 Linux 磁盘、安装 CUDA 12.8 推理环境，然后生成 2 个中间候选并筛选到
一个预算排序候选，同时单独报告它是否通过全部硬过滤条件。后续大批量正式 AI 验证仍需
在这次小规模运行通过后单独启动。
这次入口为了先验证 12 GB 级显存上的完整链路，使用缩短的采样步数；它产出的结构只用于
工程验证，不能直接当作正式候选结论。

## 你只需要准备什么

1. Windows 已安装较新的 NVIDIA 显卡驱动；不要在 WSL2 内另装显卡驱动。
2. Windows 已启用 WSL2 和 Ubuntu 24.04。若没有，只需在管理员 PowerShell 执行：

   ```powershell
   wsl --install -d Ubuntu-24.04
   ```

   重启 Windows，并首次打开一次 Ubuntu，按提示建立 Linux 用户名和密码。
3. 把下面四个项目放在 Windows 的同一个目录中，名称不要改：

   - `WINDOWS_CODEX_GPU_HANDOFF_20260829_V1/`
   - `WINDOWS_CODEX_GPU_HANDOFF_20260829_V1.TRANSFER.SHA256`
   - `WINDOWS_CODEX_GPU_HANDOFF_20260829_V1_PERSONAL_INFERENCE_OVERLAY_V1/`
   - `WINDOWS_CODEX_GPU_HANDOFF_20260829_V1_PERSONAL_INFERENCE_OVERLAY_V1.TRANSFER.SHA256`

基础包保存约 6 GB 的代码、输入和权重；名字较长的 `OVERLAY` 是一个很小的个人推理
入口附加包，不会再复制一份权重。

本入口假设文件由 Mac 直接复制到你本人的 Windows，途中没有人故意替换；这些摘要校验
主要用于发现复制或磁盘损坏。如果文件经过不可信渠道，请先把附加包的 64 位 SHA-256
摘要与 Mac 上 Codex 单独给出的摘要进行比较。

## 唯一启动命令

在上述目录打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\WINDOWS_CODEX_GPU_HANDOFF_20260829_V1_PERSONAL_INFERENCE_OVERLAY_V1\START_PERSONAL_INFERENCE.ps1
```

第一次运行会联网下载 Python/CUDA 推理依赖，可能需要较长时间；Ubuntu 若要求输入密码，
输入你首次打开 Ubuntu 时设置的密码即可。运行期间让笔记本接电并关闭自动睡眠。

脚本不会设置 SSH、开放端口或远程访问 Windows。Mac 上的 Codex 后续若要控制 Windows，
可以另行增加远程执行层；这不是本地开始推理的前置条件。

## 运行后去哪里看

- 普通总日志：`~/boltzgen_personal/logs/<本次运行编号>/quickstart.log`
- GPU 与 Python 环境记录：同一日志目录中的 `gpu_smoke.json`、`pip_freeze.txt`
- 候选结构和指标：
  `~/boltzgen_personal/workspace/boltzgen/runs/personal_vhh_smoke_20260830/<本次推理编号>/pipeline/`
- 人类可读结果摘要：推理目录中的 `RESULT_SUMMARY_ZH.txt`
- 机器可读结果摘要：推理目录中的 `RESULT_SUMMARY.json`
- 最终完成标记：推理目录中的 `RESULT_COMMITTED.json`；只有它存在且状态为成功时，
  上述两份摘要才有效。这样即使 Windows 突然掉电，也不会把写到一半的摘要当成成功。

Windows 文件资源管理器可以在地址栏输入 `\\wsl$`，再进入 Ubuntu 和对应用户的
`home` 目录查看这些文件。不要把大模型、虚拟环境或完整推理输出提交到 GitHub。

最终完成标记和总日志中的成功状态是
`PERSONAL_VHH_SMOKE_PASS_NOT_G1_NOT_G2_NOT_AIV1`。它只表示：

- Windows GPU 能加载既有权重；
- VHH 的结构生成、序列生成、复折叠、指标计算和过滤流程都执行完成；
- 本次实际使用的 3 个权重文件和分子字典运行前后完全相同。

“按预算选出”不等于“通过全部硬过滤条件”。它也不表示候选已被实验确认结合 GLP-1，
更不表示亲和力、选择性、安全性或成药性已经成立。

## 术语白话表

- **VHH**：重链抗体的可变结构域，常被称为纳米抗体；这里要生成的就是这类候选分子。
- **GLP-1**：胰高血糖素样肽-1；这里是希望 VHH 识别的计算目标肽。
- **7XL0**：公开蛋白质结构数据库中的一个编号；这里取其中已整理好的 VHH 作为首个骨架。
- **推理（inference）**：把输入交给已经完成参数学习的模型计算结果；本入口只读取现成权重。
- **生成（generation）**：模型提出新的 VHH 三维骨架和氨基酸序列候选。
- **筛选（screening/filtering）**：根据模型给出的结构、界面和抗体风险指标排序或淘汰候选。
- **硬过滤条件**：对某项指标设定的明确通过线；预算排序仍会给未全部过线的候选相对名次，
  因此摘要会把“排序选中”和“硬过滤通过”分开写。
- **checkpoint / 权重文件**：模型已经学到的参数文件，扩展名为 `.ckpt`；本入口按只读方式使用。
- **adherence 权重**：BoltzGen 的一种现成设计权重，偏向让生成结构遵守给定目标和结合位点条件。
- **逆折叠（inverse folding）**：已知候选三维骨架后，反向生成可能形成该骨架的氨基酸序列。
- **复折叠（refolding）**：再根据生成序列预测结构，用来检查它是否仍接近预期骨架和界面。
- **sampling steps / 采样步数**：生成过程反复去噪更新结构的次数；首次冒烟使用较少步数来先查兼容性。
- **GPU**：图形处理器；除显示画面外，也能并行完成模型中的大量矩阵计算，这里指 5070 Ti。
- **NVIDIA**：5070 Ti 的制造商；其 Windows 驱动负责让 WSL2 使用这块 GPU。
- **WSL2**：Windows Subsystem for Linux 2，在 Windows 内运行 Ubuntu 的官方方式。
- **CUDA**：NVIDIA GPU 的计算平台；这里使用 CUDA 12.8 版 PyTorch。
- **PyTorch**：加载模型权重并执行数值计算的软件库；这里固定使用带 CUDA 12.8 支持的版本。
- **BF16**：一种 16 位浮点数格式，可降低 GPU 显存占用；5070 Ti 支持该格式。
- **PowerShell**：Windows 自带的命令行和脚本环境；唯一启动命令在这里执行。
- **Python**：BoltzGen 和验证脚本使用的编程语言；入口会在 WSL2 内自动建立独立环境。
- **SSH**：通过网络远程登录另一台电脑的协议；本地启动入口不安装、不启用它。
- **Codex**：负责检查代码、执行既定任务并整理证据的 AI 编程代理；它不是实验测量设备。
- **GitHub**：保存代码版本的在线仓库；大权重、完整数据和推理结果不会上传到这里。
- **mmCIF / CIF**：保存蛋白质三维结构与链、残基等信息的文本文件格式。
- **NPZ**：NumPy 压缩数值文件，保存模型阶段产生的坐标、置信度等数组。
- **CSV**：逗号分隔表格文本；候选的各项筛选指标保存在这种文件里。
- **NaN**：`Not a Number`，表示某个数值计算无有效结果；脚本发现它会停止并保留日志。
- **SHA-256**：文件内容指纹；脚本用它确认复制前后没有损坏，并确认权重没有变化。
- **OVERLAY / 入口附加包**：只保存启动脚本和基础包指纹的小目录，不含第二份模型权重。
- **AIV0**：AI 验证第 0 阶段，确认输入数据的身份、完整性和隔离边界；当前基础包已完成。
- **G1**：正式 GPU 环境验收门；这次个人小规模运行不能替代它。
- **G2**：正式端到端单 GPU 验收门；参数、样本量和证据要求高于这次小规模运行。
- **AIV1**：AI 验证第 1 阶段；正式批量生成与对照评估尚需在小规模运行通过后执行。
- **AIV4**：AI 验证第 4 阶段；在配置和候选面板预先冻结后，一次性查看锁箱对照并作整批
  继续或停止决定。它不能用来重新挑选单个候选，也仍不等于实验成功。
- **锁箱（lockbox）**：在前面调配置和选候选时不得查看候选级结果的保留对照；用于检查方案
  是否能推广，而不是再次调参。
- **实验闭环**：把计算候选交给真实实验测量，再把实验结果反馈给下一轮计算；当前阶段尚未进入。
